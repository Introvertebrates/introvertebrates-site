# Website media library

This `assets/` folder contains **website copies**, not the master photo archive. Original photographs on the computer/drives should stay where they are; copy a selected image here before editing it for the site.

## Where website images live

- `about/` — creator/about photography
- `anatomy/` — crops selected specifically for anatomy and learning pages
- `archive/` — animals previously kept; these must not be presented as current collection residents
- `collection/` — current collection card/overview images
- `species/` — profile-specific images and galleries for current animals
- `kryp/` — Kryp & Krabater imagery and video-derived stills
- `media/` — broader reusable editorial/homepage imagery
- `data/` — generated/public website data; not a photo folder

## Editing rule

When a website image needs work, edit the copy inside this repository or create a new web copy beside it. Do not overwrite the original archive/master photo outside the repository.

Use descriptive filenames such as:

`theraphosa-apophysis-siuzi-profile-01.jpg`

For new images, prefer a web-sized JPEG/WebP that is large enough for the intended layout but does not carry unnecessary full-resolution camera data. Keep scientific names and animal names in filenames where practical so the file can be found later without opening dozens of mystery images.
