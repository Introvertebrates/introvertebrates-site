# Kryp & Krabater weekly feature

The weekly feature on `kryp-og-krabater.html` reads from `_data/kryp_weekly.yml`. Tina appears beside the week’s observation question, while a real animal photograph remains the main image.

## Five-minute update

1. Open `/admin/` and choose **Kryp & Krabater · Weekly feature**.
2. Replace the title, short introduction, and Tina’s question.
3. Select an Introvertebrates-owned image. A prepared 3:2 landscape crop works best.
4. Point the button to the most relevant Kryp trail or animal profile.
5. Preview and publish. The new feature replaces the previous week’s card; it does not create an ever-growing archive.

Use only Erlend’s photographs and video. The animal in the image must support the accompanying text, and named collection animals must remain correctly identified.
